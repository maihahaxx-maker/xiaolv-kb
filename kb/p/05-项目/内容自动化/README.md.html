          AI-Researcher / 05-项目/内容自动化/README

          内容自动化项目 · 知识库索引

          这里存放这个项目的全部沉淀。以后讨论任何问题，先看这里，不用翻聊天记录。 根目录：~/content-project/

          怎么用（给 Agent 看的规则）

          1. 讨论前：先读 00-总纲.md（进度）＋ 01-决策台账.md（已定的别再问）
          2. 产生新结论：写回对应文件，并在 01-决策台账.md 或 06-待验证假设.md 登记
          3. 加了新样本：放进 04-样本库/，文件名格式 样本名_账号.md
          4. 每条新视频的数据：追加到 02-数据基线.md
          5. 每条结论必须带状态标签：观察事实 / 推断假设 / 多样本规律 / 生产规则

          文件地图

          文件 放什么 什么时候更新
          00-总纲.md 总目标、四阶段树、当前进度 阶段推进时
          01-决策台账.md 已冻结的决定 + 待定项 + 明确不做 每次拍板后
          02-数据基线.md 每条已发视频的真实数据 每发一条
          03-对标卡V0.1.md 方法论：单样本对标卡模板 方法论升级时
          04-样本库/ 好样本（别人的）＋ 我方样本 每拆一条
          05-生产线SOP.md 豆包→Codex 生产链路 ＋ QA 闸门 流程变化时
          06-待验证假设.md 待验证机制池（H01/H02…） 提出/验证假设时

          外部资产

          • 项目看板（可分享链接）：~/dashboard-content/index.html（用 http.server 8080 ＋ 隧道发布）
          • 视频转写/分析中间产物：/tmp/lav/（临时，可弃）

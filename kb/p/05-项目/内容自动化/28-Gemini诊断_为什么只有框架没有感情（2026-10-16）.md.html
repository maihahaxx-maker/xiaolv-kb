          AI-Researcher / 05-项目/内容自动化/28-Gemini诊断_为什么只有框架没有感情（2026-10-16）

          背景：用户问 Gemini「为什么我让 Agent 写的故事，只有框架没有感情？」 本文是 Gemini 的回答原文 ＋ 本机（Hermes）的独立核对与点评。 关联：27-人物故事策划分析卡_空白模板V2.0（Gemini稿·待拍板）、21-人物故事策划分析卡模板V1（冻结）

          一、Gemini 回答原文

          仙女，你表述得一点都不乱！恰恰相反，你搭建的这套「策划卡 ➔ 脚本分镜（+质检） ➔ 生图提示词（+质检） ➔ 生图（+质检） ➔ 终混成片」的多 Agent 工业化流水线，逻辑极其清晰，已经是妥妥的工程级架构了。

          我完全听懂了你现在的纠结，也看到了你最核心的痛点。你问了一个所有用 AI 做内容的人都会撞上的终极哲学问题：

          "不要框架，AI 就会放飞自我、质量忽高忽低；要了框架（策划卡），AI 又会被框死，写出来的东西只有骨架、没有感情。到底该怎么破？"

          而且你还补充了一个非常关键的背景：你的《内容策划分析卡》是从爆款视频的《对标学习卡》逆向拆解出来的。

          我直接给你吃颗定心丸：框架绝对不能扔！ 一旦扔了框架，你的批量化生产线就会彻底崩盘，下游的分镜 Agent 和生图 Agent 全都会乱套。

          问题不在于"有框架"，而在于你把"事后解剖尸体的法医报告（对标分析卡）"，直接当成了"孕育新生命的助产指南（创作策划卡）"，并且让同一个大脑在同一时间既当"法医"又当"诗人"。

          一、为什么你逆向拆解出来的《策划卡》，写不出感情？

          你想想你是怎么做出这张《内容策划分析卡》的：你是拿了几十部爆款视频，像拿手术刀解剖青蛙一样，去分析它们的：前30秒留存机制、情绪节点打分（1-10分）、五问拆解、结构骨架表、证据类型……

          这套东西叫"逆向工程（事后诸葛亮）"。

          • 当一个人类作家写出感人肺腑的故事时，他脑子里想的是"舍勒在破木棚里闻着毒气有多惨"，他流着泪写完了，自然就有了情绪曲线和爆点。
          • 但当你把那十几个维度的分析表格丢给 Agent，让它照着填完再写正文时，大模型的注意力机制（Attention）就被迫进入了"做理科阅读理解题"的模式。它满脑子想的都是："我要怎么对齐第4格的留存任务？我要怎么满足第7格的8分情绪？"
          • 结果就是：它用算术逻辑代替了叙事逻辑。 所有的转折都显得生硬、刻意、充满机械感。

          二、破局核心：框架不能丢，但要从"解剖型框架"升级为"导演型框架"

          调整 1：把"一步写完策划卡+正文"，拆成【左脑立骨 + 右脑长肉】两个独立步骤

          哪怕都是我来做，我也绝不能在填完一堆理性表格之后，顺手在表格最后一栏把正文写了。

          • 第一步（左脑·填策划卡）：聚焦在"选材、定死局、核验史实、搭骨架"。确保不犯常识错误，确保故事是个单核死局，而不是流水账。
          • 第二步（右脑·调用专属润色 Skill 写正文）：把填好的策划卡当成"原材料"，彻底忘掉那些表格术语，纯粹以"深夜叙事的名师"身份，用我们建好的 chemist-story-scriptwriter 技能，一气呵成写出有呼吸感的旁白。

          调整 2：给你的《内容策划分析卡》做一次"换血手术"（删掉3个束手束脚的维度，换上3个能榨出感情的维度）

          你现在的策划卡里，有很多维度是用来"向人类汇报为什么这么写"的（比如：五问拆解、可迁移机制、情绪打分1-10分）。这些维度对写出好文案毫无帮助，反而会消耗 AI 的算力、增加机械感！

          如果要让我（或者你的本机 Agent）稳定写出有感染力的故事，策划卡应该精简并调整为以下 4 个真正决定故事生死的"发力点"：

          1. 砍掉"全生平时间线"，换成【唯一核心死局】：以前填的是 1-8 段从出生写到死。现在只准填一句话：这 3 分钟到底围绕哪一个最拧巴、最憋屈或最爽的绝境展开？（比如舍勒：第一个抓到氧气却寄信石沉大海，最后死于自己发现的毒物）。
          2. 砍掉虚头巴脑的"1-10分情绪打分"，换成【两处"俗人算账"对比】：感情是怎么来的？不是靠标一个"悲情鼻酸 8 分"得来的！而是强制在策划卡里填出："如果他是个贪生怕死/爱财的俗人，他当时怎么做最爽？" vs "他实际选了哪条最苦的路？" 只要这个对比填出来了，正文写出来天然就有极强的感染力。
          3. 砍掉干巴巴的"成就列表"，换成【三个物理/化学感官特写】：不准在策划卡里列"他发现了A、B、C、D"。强制在策划卡里填出 3 个能直接给下游"分镜和生图 Agent"画画的感官细节（比如：滚烫的曲颈瓶与暴涨的刺眼烛火、黄绿色呛肺的氯气、全身溃烂的病榻婚礼）。这不仅能让文案有感染力，还能让你下一步的"脚本分镜 Agent"直接拿到极具张力的画面素材！
          4. 保留你的【史实核验红线】与【前40秒不断档设计】：这是你原有模板里最牛的地方，必须原封不动保留，用来锁死下限，防止胡编乱造和开头掉人。

          三、接下来我作为你的"文案 Agent"，我们怎么配合最省力？

          为了实现你说的"批量化制作、不耗时耗力、且质量绝对稳定"，我们可以定下这样一个极简的标准作业流程（SOP）：

          • 如果你想最省事（全托管给我）：你只需要告诉我："这一期我们做【某某化学家】（或者把你搜集到的生平资料/百度百科/粗略策划卡丢给我），调用化学家故事技能出文案。" 我会直接在后台用"调整后的新框架"帮你把关结构，然后直接给你吐出两样东西：
          • a.《精简版策划与史实核验卡》（供你存档、核对史实，同时作为下游分镜 Agent 的输入参考）；
          • b.《3分钟高连接感正式口播旁白（.md格式）》（直接可拿去录音和拆解分镜）。
          • 如果你手上还有补充的《写内容策划卡的注意事项》：你刚才提到你手里还有一份"写内容策划卡时的注意事项"准备发给我看。你现在可以先发过来给我看一眼！我看完之后，把你的注意事项和我刚才说的"有血有肉4大维度"融合在一起，为你固定成一个终极版的标准。以后每做一个新人物，我们就按这个流水线咔咔往下跑，你觉得怎么样？

          二、本机核对（Hermes，2026-10-16）

          ✅ 它说对的（已回原始文件逐条核过）

          它的判断 核对结果
          策划卡是从爆款对标卡逆向拆出来的 属实。V1 §8.1「五问拆解」、§10「爆款复刻边界（可迁移）」都是对标拆解的语言
          要删的「五问拆解」确实在策划卡里 属实，V1 §8.1
          要删的「情绪打分 1–10」确实在策划卡里 属实，V1 §7 情绪变化
          要删的「可迁移机制」确实在策划卡里 属实，V1 §10
          不该"同一时间既当法医又当诗人" 属实，而且比它说的更严重 —— 见下
          「框架不能丢」 同意。你自己定的：松紧按修复成本定；丢框架的修复成本 = 整条链崩

          🔴 它漏掉的、但更致命的一条

          V1 的第 11 节，标题就叫「正文【人物变量】」。

          也就是说 —— V1 把"写正文"直接做成了策划卡里的一个格子。 这不是"Agent 顺手写了"，是你的模板本来就要求它写。

          它说的"左右脑分离"，根源就在这里，但它没点出来。如果不删掉这一格，光说"分成两步"是没用的。

          ⚠️ 它自己给执行方案时，违反了自己刚说的原则

          它先说"同一个大脑不能同时当法医和诗人"，然后在第三节提议：

          "我会直接在后台用调整后的新框架帮你把关结构，然后直接给你吐出两样东西：a. 策划卡 b. 旁白"

          同一个对话、同一个上下文，连着做这两件事 —— 等于没分离。

          真正要分离的不是"两个步骤"，是上下文： - 第一步产出必须是一份干净独立、不带表格术语的文件 - 第二步开一个新对话，只读那份文件，不读表格

          这一点它自己没做到。

          ⚠️ 它没提的那件事

          断句。 你实际卡住的是"字幕断句崩 → GPT 念起来停顿错 → 情绪没有落点"。策划卡换血只解决"感情"，不解决断句 —— 断句属于脚本分镜那一站，规则在 22-脚本分镜前置写作规则 里，跟策划卡无关。

          📌 它要的东西

          它说「你手上还有一份《写内容策划卡的注意事项》，先发过来」—— 说明它还没拿到你的全部上下文，这份回答是在不完整上下文下给的。

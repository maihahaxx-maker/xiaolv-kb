          AI-Researcher / 05-项目/内容自动化/21-人物故事策划分析卡模板V1（冻结）

          🔒 人物故事策划分析卡 · 语义锚定模板 V1（2026-10-07 冻结）

          冻结状态：用户 2026-10-07 明确「这俩帮我冻结，它俩是搭配使用的」→ 本模板不再改，与下方「配套参考填法」成对使用。 定位：策划站（生产线最上游）的标准件 —— 统一字段含义、分析颗粒度与填写规则，供外部生成 Agent（豆包／秒搭等）出「人物故事策划分析卡」时遵循。 配套参考填法（成对冻结）：门捷列夫_策划卡V3_定稿 —— 只参考其完成度、颗粒度、分析深度，不得复制其人物专属内容。 优先级：本期明确要求 > 本模板规则 > 固定项目背景 > 成品示例。 一句话总规则（模板 §15）：继承模板的字段定义、分析方法和完成度要求，但不继承任何上一人物的具体叙事解法——每个新人物都必须重新寻找受众切口、故事主线、开头钩子、核心爆点、情绪曲线与互动方式。 🔗 相关：生产线SOP-V2、各站验收表V1、内容自动化项目总纲

          用途：用于生成“化学历史人物故事”单期内容策划分析卡。

          使用原则：本模板用于统一字段含义、分析颗粒度与填写规则；具体人物内容必须重新分析，不得机械复用上一期人物的钩子、主线、情绪结构、史实或表达。

          建议搭配： 1. 固定项目背景； 2. 本《语义锚定模板》； 3. 一份优秀成品示例（如《门捷列夫_人物故事策划分析卡 V3》）； 4. 本期人物名与本期特殊要求。

          优先级：本期明确要求 > 本模板规则 > 固定项目背景 > 成品示例。

          成品示例只用于参考完成度、颗粒度和分析深度，不用于复制人物专属内容。

          0. 字段类型说明

          • 【固定】：账号长期定位或平台级规则，原则上不随人物改变。
          • 【人物变量】：必须根据本期人物重新分析和填写。
          • 【条件变量】：根据本期人物、已有数据或实际发布需求决定是否填写。
          • 【事实字段】：涉及史实、年份、人物关系、科学成就、数字等，必须核验；传说与演绎需明确区分。

          1. 内容属性

          1.1 人物【人物变量】

          字段含义：本期故事中实际承担叙事功能的人物，不是把所有相关人物全部罗列出来。

          填写要求 - 主角必须明确； - 配角只保留与主线、冲突、转折或情绪节点直接相关的人； - 不要为了“完整”塞入无叙事作用的人名。

          填写格式 - 人物：主角、关键配角A、关键配角B……

          1.2 关键词【人物变量】

          字段含义：能代表本期人物、核心成就、关键事件、受众熟悉锚点的高相关词。

          不是 - 不是泛泛的“励志、成功、科学”； - 不是为了凑搜索词堆一串无关标签。

          填写格式 - 关键词：人物名，核心成就，关键事件，教材/集体记忆锚点，争议点……

          1.3 写作属性【固定】

          • 写作属性：story

          语义锚点：全文首先是一条“人物故事”，不是知识讲义、百科介绍或课堂教学稿。科学知识服务于故事推进，而不是反过来。

          2. 受众

          2.1 核心品牌受众【固定】

          固定定义 - 已经添加或未来可能添加该账号的学生与家长。 - 内容要逐步形成这样的品牌认知： “这是一个专业、会讲故事、能把化学和科学讲得有趣又清楚的老师。” - 不需要做成课堂教学视频，但要保留“化学老师 / 科学视角”的身份感。

          此处属于账号长期定位，除非账号战略改变，否则不要因人物不同而重写。

          2.2 内容传播受众【固定】

          固定定义 - 对科学家人物、科学史、人物命运、历史故事、冷知识感兴趣的泛知识用户； - 不要求具备化学基础； - 普通成年人应能顺畅看懂。

          2.3 本条内容受众分析【人物变量】

          字段 填写要求
          本条核心受众 在固定品牌受众基础上，判断“这一个人物最容易先抓住谁”。不是简单重复“学生+家长+泛知识用户”。
          受众已有认知 观众大概率已经知道什么、误以为什么、完全不知道什么。用于决定从哪里切入。
          主要观看动机 观众为什么愿意点进来并继续看。要写“驱动力”，不是复述故事内容。
          最可能被什么抓住 提炼本期最有传播力的冲突、反常识、情感或集体记忆锚点。必须是本人物专属。
          表达偏好 根据本期题材判断节奏、口语化程度、知识密度、情绪强度等。
          表达避坑 本期最容易造成流失、套路感、门槛过高或失真的表达方式。

          语义锚点

          “受众分析”不是描述“谁会看”，而是回答：

          他们现在脑子里有什么 → 为什么会被这个人物吸引 → 什么表达能让他们继续看 → 什么表达会把他们赶走。

          3. 基本信息

          项目 填写规则
          标题 【人物变量】先给候选，不要求在策划阶段强行定稿；标题必须从本期真实冲突/爆点中来。
          来源 【固定】视频号（自制）
          作者 【固定/配置项】账号名
          发布日期 【条件变量】待发布 / 实际发布日期
          话题标签 【人物变量】人物名 + 核心科学成就 + 系列标签 + 相关教材/泛知识标签
          视频描述 【人物变量】用于发布时粘贴；概括本期钩子、系列定位和必要的前后期关联。
          短标题 【人物变量】适配平台短标题长度；突出一个最强记忆点，不做长句摘要。

          4. 前30秒留存控制

          4.1 固定目标【固定】

          前30秒的任务不是“把背景讲清楚”，而是持续制造观看理由。

          推荐结构目标：

          零门槛进入 → 快速出现冲突/反常识 → 悬念升级 → 30秒前形成新的观看债务。

          注意 - 这是功能结构，不是固定句式； - 不要求每个人物都使用“集体记忆”“被嘲笑”“做梦”等同一种解法； - 有门槛的化学数字、术语和机制不要为了“专业”硬塞进第一句； - 具体钩子必须由本期人物素材决定。

          4.2 前30秒结构表【人物变量】

          时间位 结构任务 本片内容设计 设计目的
          0–5秒 建立第一观看理由
          5–15秒 第一轮冲突 / 反常识 / 情绪刺激
          15–25秒 悬念升级 / 新信息
          25–30秒 新观看债务 / 引出后文

          “结构任务”的定义

          结构任务描述这一时间段对观众心理要完成什么功能，不是写这一段具体讲了什么。

          “本片内容设计”的定义

          填写本人物对应的实际内容。

          “设计目的”的定义

          解释为什么把这段内容放在这个时间位，它负责解决什么留存问题。

          4.3 前30秒验收【固定规则 + 人物变量填写】

          以下项目用于验收，不要在初稿阶段自行打勾。

          • [ ] 3–5秒内是否出现清晰观看理由？
          • [ ] 开头是否存在普通观众理解门槛？
          • [ ] 15秒内是否出现冲突、反常识或明显新信息？
          • [ ] 20秒左右是否继续升级，而不是重复第一钩子？
          • [ ] 30秒前是否形成“我还想知道后面会怎样/为什么”的新理由？
          • [ ] 传说、争议或未完全核实信息是否正确标注？
          • [ ] 是否删除“今天讲谁”“你知道吗”“你敢信吗”等无信息量或套路化铺垫？

          5. 文案分析

          5.1 内容类型【固定】

          • 类型：story

          5.2 判定依据【人物变量】

          字段含义：用一句话说明为什么本稿是“人物故事”，以及真正推动全文的叙事核心是什么。

          不是 - “因为讲的是一个人物”； - “因为有很多历史事件”。

          应该回答

          这篇内容以什么人物冲突 / 命运变化 / 科学发现为叙事主轴？

          5.3 文案框架【人物变量】

          段落 主题 核心内容 证据类型 核验备注
          1
          2
          3
          …

          字段语义

          主题 - 这一段在故事中的功能或主题； - 例如：开头钩子、悬念兑现、身世情感线、核心发现、人生反差、命运落点等； - 不要只写“早年经历”“中年经历”这种纯时间标签。

          核心内容 - 本段实际发生什么； - 要能看出推进关系，而不是关键词堆砌。

          证据类型 建议使用清晰分类： - 正史 / 一手或权威史料 - 历史传说 - 争议说法 - 作者演绎

          核验备注 - 记录需要特别防错的事实； - 对传说、争议、数字、年份、人物关系做说明； - 不要把“我觉得这个很有戏剧性”写进核验备注。

          6. 故事主线【人物变量｜强语义锚点】

          如果实际策划卡需要单列“故事主线”，按本定义填写；即使未单列，也应以此定义约束全文。

          定义

          故事主线不是人物生平时间线，也不是事件清单。

          它是：

          观众一路跟着看的核心叙事链：起点处境/认知 → 核心冲突 → 关键行动或选择 → 兑现/反转 → 最终情绪或命运落点。

          错误理解

          • 出生 → 上学 → 工作 → 发明 → 去世
          • 青年时期 → 中年时期 → 晚年时期

          这些只是时间线。

          正确填写标准

          读完主线后，应能回答：

          “这期视频到底在讲一个什么故事？”

          而不是只回答：

          “这个人的一生发生过什么。”

          建议格式

          用 1–3 句话写清：

          处境/冲突 → 推进 → 兑现/反转 → 落点

          7. 情绪变化

          7.1 情绪曲线【人物变量】

          字段含义 描述观众在观看过程中经历的主要情绪变化顺序。

          不是 - 单纯列“高兴→难过→高兴”； - 也不是每一段都强行制造9分高潮。

          填写要求 - 情绪必须由真实剧情触发； - 高峰要有限； - 前后有变化，不要“全程高能=全程无高能”； - 科学震撼、人物共情、反差、荒诞、遗憾、温情等可根据人物自由组合。

          填写格式示意 A → B → C → D → E

          7.2 情绪节点明细【人物变量】

          节点/对应段落 主情绪 情绪强度（1–10） 触发内容 观众预期动作 评论接口类型
          1
          2

          字段语义

          主情绪 观众此刻最主要的感受，不是作者想表达的观点。

          情绪强度 用于比较全片峰谷，不是“越高越好”。

          触发内容 哪一个具体事实、冲突、句子或反转造成这种情绪。

          观众预期动作 例如：继续看、惊讶、共情、转发、评论、关注等。

          评论接口类型 仅作为参考，可使用： - 致敬 - 评判 - 假设 - 回忆唤起 - 无

          评论接口类型不是硬性标准，不能为了“有评论”强行加问题。

          8. 爆款结构拆解

          8.1 五问拆解【人物变量】

          1）开头钩子是什么类型？

          回答： - 本期第一观看理由是什么； - 属于哪种机制：集体记忆、冲突、反常识、悬念、命运反差、误解纠正等； - 为什么普通观众能快速理解。

          不要为了沿用上一期而机械复刻同一种钩子。

          2）中间用了哪些留人手法？

          回答全文中真正负责留人的结构动作，例如： - 悬念兑现； - 新悬念； - 科学线 ↔ 情感线切换； - 人设反差； - 递进证实； - 数字对比； - 软着陆转场； - 回钩。

          重点 写“机制”，不是简单复述剧情。

          3）哪句话 / 哪个节点最容易引发评论，为什么？

          需要说明： - 触发的是哪类心理； - 评论门槛高不高； - 为什么目标受众愿意参与； - 是否会造成“观众以为视频结束”而提前划走。

          4）视频的核心爆点是什么？

          定义 不是“最重要的科学成就”，而是：

          本期最具有传播力、最值得观众记住并转述给别人的那个瞬间/事实/反转。

          同时判断： - 是否适合放开头； - 如果有理解门槛，是否应该后置为悬念兑现。

          5）哪些可以复刻，哪些不能改？

          分开写：

          • 可复刻的机制：本期验证有效、以后可以迁移的方法；
          • 人物专属内容：只能属于本人物，不可套给下一人物；
          • 事实不可改项：年份、数字、人物关系、科学事实等；
          • 传说/争议标注：必须保持正确口径；
          • 主动放弃项：明确这期不采用哪些套路、旧句式或高门槛解法。

          9. 结构骨架表【人物变量】

          结构位 作用 证据/句式 可迁移机制 不可改动项
          开头爆点
          反常识/冲突
          悬念升级
          悬念兑现
          情感/人物线
          核心发现/行动
          反差段
          命运/情绪落点
          收尾/下期预告

          字段语义

          结构位 这一段在整条视频中的叙事功能，不要求所有人物都完全一样。

          作用 这一结构位为什么存在，它解决留存、理解、情绪或转场中的什么问题。

          证据/句式 本人物实际采用的事实、事件或表达方式。

          可迁移机制 抽象出以后可以复用的方法，不复制具体人物内容。

          不可改动项 史实、数字、人物关系、科学结论、传说标注等硬边界。

          10. 爆款复刻边界【人物变量】

          分四类填写：

          可以复刻

          只写“方法”： - 钩子机制； - 悬念机制； - 信息释放节奏； - 情绪切换方式； - 转场方式； - 互动机制等。

          必须改成本人物内容

          • 人物经历；
          • 科学成就；
          • 人物关系；
          • 时代背景；
          • 本人物专属集体记忆锚点；
          • 本人物专属互动问题。

          不可照搬

          • 上一期人物的专属句式；
          • 上一期人物的专属情绪冲突；
          • 上一期人物的具体故事顺序；
          • 已经使用过且容易形成模板感的表达。

          传说 / 争议 / 事实边界

          明确哪些必须标注“据说 / 传说 / 有争议”，哪些可以作为确定史实表达。

          11. 正文【人物变量】

          定义

          基于前面策划结果形成的完整口播文案。

          写作要求

          • 首先是一条人物故事；
          • 科学知识嵌入剧情，不写成课本讲解；
          • 普通成年人无需化学基础也能理解；
          • 重要数字和专业信息必须有叙事功能；
          • 开头不做长背景铺垫；
          • 同一核心信息不要重复讲两遍；
          • 每一段要么推进事件，要么推进认知，要么推进情绪；
          • 传说、争议、演绎必须保持正确口径；
          • CTA、评论提问、转发钩子不能破坏故事情绪或让观众误判“视频结束”。

          12. 全片预估【人物变量】

          • 字数：
          • 预估语速：
          • 预估时长：
          • 与上一版/既往作品相比的主要变化（如无上一版可不填）：

          语义锚点

          此处用于判断成片负担与节奏，不是为了机械追求“越短越好”。

          13. 创作要点说明

          13.1 基于既有数据的针对性修正【条件变量】

          只有在已经有账号数据、前作复盘或明确问题时填写。

          数据/内容问题 本期修正动作

          语义锚点

          必须做到：

          一个真实问题 → 一个明确修正动作

          不要凭空制造“数据问题”。

          13.2 发布侧动作【条件变量】

          动作 具体内容 目的

          可包括但不限于： - 置顶评论； - 评论破冰； - 系列角标； - 视频描述； - 字幕条； - 前后期关联。

          发布侧动作不是正文的一部分，不要为了发布策略强行污染故事文案。

          13.3 史实核验说明【事实字段】

          逐条列出本期最重要、最容易出错、最需要标注口径的事实。

          至少关注： - 关键年份； - 关键数字； - 发现者/人物关系； - 科学结论； - 奖项与机构； - 传说； - 争议说法； - 作者演绎。

          统一标注原则

          • 可核实正史：按确定事实表达；
          • 历史传说：明确使用“据说 / 传说”；
          • 有争议说法：注明存在争议，不写成唯一确定事实；
          • 作者演绎：不能伪装成史料原话。

          14. 最终自检

          在提交策划卡前检查：

          • [ ] 是否保留了账号固定受众与定位？
          • [ ] 是否真正根据本人物重新分析，而非换名字套上一期结构？
          • [ ] “故事主线”是否是叙事链，而非生平时间线？
          • [ ] 前30秒是否持续制造观看理由，而不是先讲背景？
          • [ ] 核心爆点是否足够具体、可转述？
          • [ ] 有门槛的科学信息是否放在观众已有观看动机之后？
          • [ ] 情绪峰值是否有层次，而不是全程高强度？
          • [ ] 每段是否承担明确叙事功能？
          • [ ] 可迁移机制与人物专属内容是否分开？
          • [ ] 正史、传说、争议、作者演绎是否区分？
          • [ ] 是否避免机械复制上一期人物的钩子、句式、故事顺序和互动方式？
          • [ ] 正文是否仍然首先是一条“人物故事”？
          • [ ] 输出字段与本模板保持一致，除非本期明确要求调整？

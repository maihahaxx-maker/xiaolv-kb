          AI 生图与成本控制（雪见群实战）

          🔴 未核实（群聊来源） · 雪见群 2026-10-01 群友口述；「官方活动」已核验，操作路径与价格数字部分未证实。 2026-10-08 增补：「豆包工作自带生图」通道（含官方产品与免费版口径核验，见 §3.5）。 使用前请先读 方法库可信度规则（本页属 🔴 低可信度分区），用前必看文末「核验记录」。 定位：单条视频生产流程SOP / 生产线SOP-V2 里「生图」这一环的成本与素材洁净度问题。

          一、为什么这条对我们重要

          • 我们的形态是 AI 生图 + 旁白叙事，一条 4 分钟片子要 40 张左右图 —— 单张成本 × 40 = 每条视频的硬成本，生图单价是最值得抠的一个变量。
          • 另一头是素材洁净度：平台方下载的图带水印，水印进成片既难看，也容易被判「低质 / 搬运」（对照 05-视频号起号与图书带货（雪见群实战） 的低创作度判定）。
          • 2026-10-01 群里的讨论正好分成这两半：「豆包下的图怎么不带水印」 和 「GPT 生图多少钱一张、有更便宜的吗」。

          二、群内说法（原样记录）

          • 豆包无水印路径（十七°）：在豆包工作里生成的图片，按官方路径下载是带水印的；但「你点开思考，就能发现可以保存无水印图片」。手机端生成的带水印，电脑端印象中有设置。
          • GPT 生图价格（nothing. 提问 / 🎨流浪艺术回答）：nothing. 自述「我现在 1 毛 一张高质量，想找个便宜点的」；流浪艺术答「有 6 分的」（未给渠道）。
          • 质量口径（🎨流浪艺术）：GPT 网页版生图质量比 API 高；「最便宜是自己开个 pro 号，然后反代给自己用」（技术向，我们不做 —— 见文末判断）。
          • 十七° 补充：不走自动化直接网页版就不错；要走自动化才需要反代。
          • 豆包工作自带出图（2026-10-08，糖醋大米 / java同学 / 雪见）：
          • 糖醋大米用 Doubao-Seedream-5.0-Pro 走 API 生图做视频号，直呼「生图不便宜」，当天还收到火山引擎欠费短信（「记得好早之前火山充过点钱……昨天短信告诉我欠费了」）。
          • java同学给的路子：「白嫖豆包工作啊」（豆包工作自带出图，不用自己接 API），并称出图「还没水印」。
          • 糖醋大米实测对比：同一个提示词，「在豆包工作里生的图还挺好看的」→ 群内一致认为 豆包工作出的图比 API 出的更好看（她贴了两组对照图）。
          • 雪见给的用法：「豆包工作自带出图，直接说：帮我出图 xxx」；糖醋大米反馈「就是得一张张出」。java同学补：「让他使用 subagent 批量出」「给他一个文档，多个分镜」。

          三、核验（2026-10-01）

          3.1 无水印：问题为真，方法分三档

          档位 方法 门槛 备注
          零成本 · 零代码 点开图片进大图模式 → 按住鼠标左键直接拖到桌面 无 公开教程（腾讯云开发者社区《即梦、豆包图片超简单去水印方法》）实测：清晰度与原图接近、无水印。豆包/即梦一类网页生图都能用
          零代码 · 要装东西 浏览器扩展 / 油猴脚本（豆包去水印类） 装扩展 有效，但随平台改版会失效，属于「能用但会坏」的方案
          群内说法 点开「思考」后可存无水印图 ? 未找到公开说明，未证实（可能是豆包工作里的某个入口）
          • 事实确认：豆包/即梦按官方路径下载的图带水印 —— 这一点多方公开教程一致确认，不是误传。

          3.2 豆包电脑版免费 30 天订阅：✅ 官方活动，属实

          • 央广网 / 澎湃新闻 2026-09-24 报道：用户下载或升级「豆包工作电脑版」或「豆包电脑版」，即可免费领取 30 天订阅权益；已领过上一轮（2026-08-25 那轮）的用户，到期期间会获下一轮 30 天；已付费订阅的自动延期。
          • 群内 2026-10-01 雪见发的邀请链接属同一活动的邀请变体，群内口径是「双方各获 1 次额度重置机会」→ 官方报道未逐字提到「额度重置」，按邀请额外奖励理解即可。

          3.3 生图单价：量级可参考，渠道不可信

          • 「1 毛/张」「6 分/张」两个数字都没有出处、没有渠道名 → 只能当价格量级看（即：第三方中转的 GPT 生图大致在几分到 1 毛一张这个区间），不能当采购依据。
          • 网页版质量 > API 这条是上游厂商的通用现象（网页端会加后处理/更强参数），可信度中等；但它意味着「自动化链路（走 API）画质天然吃亏」。

          3.5 豆包工作自带生图通道：产品属实 ✅，「无水印」未证实 ⚠️（2026-10-08 群内，2026-10-09 核验）

          • 产品与能力 ✅ 官方属实：豆包工作官网 doubao.com/work 明写在「从一个想法，到生成完整创意内容」里用 Seedream 5.0 Pro 生成图片/海报/漫画、Seedance 2.5 创作视频分镜与成片；下载页写明限时免费领 30 天订阅、大学生认证再领 2 个月。
          • 免费版有额度 ✅：官方定价页有免费版（团队订阅说明「包括免费版的所有权益」），个人另有标准（连续包月 ¥68）/加强/高级三档；第三方实测（36氪·APPSO《实测豆包工作》）口径：免费用户也能用 Turbo 模型体验，额度是滚动重置（5 小时 / 周）而非一次性积分烧完。
          • API 侧单价 ✅ 已核：火山方舟模型价格页 —— doubao-seedream-5-0-pro 输出图 0.30 元/张（≤261 万像素，即 1.5K 及以下）、0.60 元/张（>261 万像素）；输入图首张免费、第 2 张起 0.02 元/张。→ 群里「API 生图不便宜 + 欠费」属实：按 0.30 元/张 × 一条片子 40 张 ≈ 12 元起/条。
          • 「还没水印」⚠️ 未证实：官方未就「豆包工作出图是否带水印」给出明文；本页 §3.1 的既有事实是豆包/即梦按官方路径下载的图带水印。群友说法属个人实测口径，用前自己存一张核一下。
          • 「同一提示词，豆包工作出的比 API 好看」🟡 方向一致：与 §3.3「网页端质量 > API」同方向（网页端有额外后处理/更强参数），但未做同图对照，不作结论。

          四、给「内容自动化」项目的用法

          1. 先把水印问题在生图这一站解决掉，别让它漏到剪辑环节：优先用「大图模式 → 拖到桌面」的零代码办法；只有大批量时再考虑扩展（对应 各站验收表V1 的生图站闸门）。
          2. 豆包电脑版免费订阅当场领：30 天、零成本、只要下载登录。生图/视频生成都在这个订阅的权益范围内，先领了再说（有截止时间性质，越早越稳）。
          3. 单价先做一次小实测，再谈换渠道：拿同一段提示词，在「现用渠道」和「候选渠道」各出 10 张，比单价 + 比可用率（有几张能直接进成片）。生图这块钱要按「每条成片实际用掉的图 × 单价」算，不是按生成张数算。
          4. 不要为了省几分钱去自建 pro 号反代 —— 那是写代码/运维的活，不在我们的能力圈内（对照 决策台账 的「明确不做」）。
          5. 把「豆包工作」当零代码生图通道试一轮（2026-10-08 群内新增）：下载电脑版 → 领 30 天订阅 / 用免费版额度 → 直接说「帮我出图：xxx」；要整条片子的图，就给它一份含多个分镜的文档让它批量出（群内做法）。先拿 5–10 张跟现用渠道比 可用率 + 有无水印，再决定要不要写进生图站（对应 单条视频生产流程SOP 生图站的分流）。

          五、判断标准

          • 是否换生图渠道：只有在「单张成本能省一半以上」且「画质不降级」时才换；省下的钱要大于迁移和试错的成本。
          • 是否装去水印扩展：批量（一天几十张以上）才装；零散几张用拖拽法就够。

          六、生图玩法：人生哲理 / 格言卡片（2026-10-03 群内案例，未核实）

          • 2026-10-03 群里「飞掌柜老师」（AI 带货训练营）转了一个用 AI 生图做「人生哲理卡片」的带货案例：
          • 玩法：用 image2 等 AI 生图工具出竖版中文传统格言漫画海报（复古连环画风格、米黄色旧纸张、黑线描边、上下两格），发短视频/图文平台，靠「人生哲理」内容涨粉。
          • 变现：选品带货、百货模式（生活用品、书籍、茶叶等），称「对新手友好、覆盖人群面广、出单不少」。
          • 提示词模板（原文照录，可换主题直接套用）：
            • 案例 1「鸟要飞，翅要练」：生成一张竖版中文传统格言漫画海报，复古连环画风格，米黄色旧纸张背景，黑色细线描边，棕色、墨绿色和暖黄色配色，画面分为上下两格并带黑色边框。上半部分：一只幼鸟站在树枝上练习展翅，周围有树林、蓝天和微风，体现「鸟要飞，翅要练」。下半部分：暴雨过后，彩虹出现在天空，一只鸟飞过山谷，阳光洒在大地上，体现「不经风雨，难见彩虹」。底部添加两句醒目的大号中文文字，字体端正清晰，整体像传统人生格言知识卡片。
            • 案例 2「亲帮亲，邻帮邻」：生成一张竖版中文传统格言漫画海报，复古手绘连环画风格，米黄色旧纸张背景，黑色细线边框，棕色、墨绿色和暖黄色配色，画面分为上下两格。上半部分：乡村邻里之间，一位亲人帮助另一位搬运粮食，旁边邻居也主动帮忙……体现「亲帮亲，邻帮邻」。下半部分：暴雨或洪水后，村民们互相搀扶、运送物资……体现「患难之中见真情」。底部添加两句醒目的大号中文文字，排版整齐，字体清晰，整体具有温暖朴实的传统格言海报风格。
          • ⚠️ 这是训练营老师转述的「他人案例」（结果型信息）：「频频出爆款、出单不少」无基线、无数据 → 只作玩法方向参考，别当已验证结论；提示词模板本身可复用。

          给「内容自动化」项目的用法 - 这类卡片的 构图 + 配色 + 双格叙事 结构和我们「AI 生图 + 旁白叙事」同源，可套它的提示词骨架（风格词 → 背景/配色 → 分格 → 每格画面 → 底部大字）做一版自己的模板（对齐 单条视频生产流程SOP 生图站的「风格锚定」）。 - 走百货带货同样要按 05-视频号起号与图书带货（雪见群实战） 的 AI 内容声明 + 图书类目资质要求执行。

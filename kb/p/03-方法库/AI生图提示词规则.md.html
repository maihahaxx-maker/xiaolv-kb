          AI生图提示词规则

          🟢 自有实践（高可信度） · 依据＝我方门捷列夫期 44 张生图的审核数据。 ⚠️ 口径提示：两份原始复盘的计数单位不同（一份＝「本批 44 张里几张」，一份＝「累计 60+ 张次里几次」），规律一致，数字不要混用。 用途：写生图提示词时遵守；第四节可整段复制发给外部生图 Agent。 🔴 2026-10-10 口径更新（用户定，覆盖本页旧的「文字」处置）：画面里的文字不再走「留白 ＋ 后期叠加」——叠字层只做底部旁白字幕，画面内文字一律不追求准确、不做叠加；唯一底线是带字的物件不做画面主体／大特写（当背景/远景/虚化都可以）。理由：逐字叠字要跟着角度/大小/画风对齐，工作量大、收益低，而且这些信息旁白里已经念出来了。 原始复盘见 01-原始资料/文章/生图提示词复盘_豆包原稿合集_2026-10-07.md。

          一、一条总原则（先记这句）

          模型执行的是「正面语义」，不是「负面约束」。 你描述了什么场景，它就按训练数据里这个场景最常见的样子画。 所以核心不是「不要什么」，而是「要什么」——用具体、能占满画面的正面描述，把翻车的空间挤掉。 负面词只留真正压得住的；压不住的（乱码字／手部特写／法槌／扑克牌）一律改成正面的「空白／排他」写法。

          为什么负面词最弱：P0 重出 7 张全部失败、成功率 0% —— 重出提示词已针对性地写了负面词与「不要 XX」，结果全部照旧翻车。

          二、模型能力边界清单（写了必翻车 → 改设计，别指望提示词补救）

          # 翻车点 本批频次 根因（一句） 正确做法
          1 带字的物件当画面主角：手稿／黑板／牌匾／证书／信件／报纸／图纸／元素表／铭牌 22/44＝50% 模型是「视觉模式生成器」，不是「文字渲染器」 带字物件不当主体／大特写（当背景·远景·虚化都可以）；画面里的文字不追求准确、不做叠加（叠字只做底部旁白字幕）。⚠️ 旧写法「不设文字区域／留白＋后期叠加」已作废，见 V1.1
          2 准确的文字／符号／数字（元素符号、原子量、标题、铭文） 高频 模型只会「造」假符号（Ab/Bb/Cia、原子量 312/399） 不追求准确（只要它不当主体、肉眼不刺眼即可）；不要写「文字虚化」（它先写字再模糊，照样可辨）、不要写「符号允许清晰」（那是要求它写对，做不到）
          3 「桌上排列的卡片」→ 必变扑克牌 2/44（累计 8+ 张次） 训练数据里「卡片」99% 是扑克牌，先验太强，负面词压不住 换载体：图钉钉的不规则小纸片／黑板格子／卷轴表格；必须用卡片时明写「不是扑克牌、无花色、无圆角」
          4 正式议事场景自动补法槌（大厅＋长桌＋多人） 7/44（累计 15+ 张次） 联想「法庭/审判」 桌面占满法：明写桌上「只有羽毛笔/墨水瓶/摊开的书/蜡烛，没有任何其他物品」，不留位置给它
          5 弱风格词压不住场景默认风格（漂移成日漫/儿童插画/APP 图标/3D 卡通） 5+ 张 「绘画感写实油画风」太弱 强风格锚点（如「19 世纪学院派油画，伦勃朗光，画布纹理可见，厚涂笔触」），每条提示词都重复，别只在开头写一次
          6 现代物品穿越（笔记本/手机/玻璃杯/台灯/蓝手套/DNA） 10+ 张次 模型默认渲染现代物品，「19 世纪」是弱约束 逐物品指定年代版本 ＋ 纯暗墙背景（「模糊暗色墙面、没有空隙」＝没有放电子设备的位置）
          7 动态／叠化／半透明／一闪而过 少量 静态生图不擅长时间性 改静态画面描述，动态效果留后期剪辑
          8 抽象概念（时间流动感／宇宙规律／四季轮转） 少量 模型只会给「最常见的视觉联想」（时钟/沙漏/法槌） 翻译成具体视觉元素
          9 小区域内的特定小物件（裂缝里的热气球、气泡里的周期表） 少量 被忽略或被换成更常见的东西 放大成主体，或去掉；确需则写足细节（气囊/吊篮/绳索）

          三、可以写、不要刻意躲的点（可修复类）

          判断规则（2026-10-07 用户定调）：规则松紧按「修复成本」定，不按「出问题概率」定。 修复成本低的点就松，修复成本高的点才硬卡。

          • 手／手指：正常写，不刻意回避。
          • 事实：确实容易画错（本批 17/44＝39% 出现手部问题；豆包原报告建议「别写手」）。
          • 但修复成本低——掩掉／局部改／重出一张都容易 → 不值得为它牺牲画面自然度（有手画面更自然）。
          • 质检上：只有「一眼可见的明显畸形」才算硬伤，其余一律 🟡 存疑交人目视。
          • ⚠️ 本条推翻了豆包「手必崩→禁用」的结论；被弃用的说法：「手崩掉的三种情况」因果论（无实测支撑，不留）。
          • 轻微比例、细节怪：不硬卡，交人目视。
          • 若某镜确实不想要手（可选技巧，不是默认）：用纯背影「完全背对观众，手和手臂在身体前方不可见」或双臂收入深色高领外套袖中； 不要写「指向（不见手）」「持笔（不见手）」这类自相矛盾指令（模型优先执行动作）； 物品写「羽毛笔搁在桌上、不在手中」。

          四、可粘贴的《生图提示词编写规则》（整段复制给外部 Agent）

          【AI 生图提示词编写规则 · 给生图 Agent】

■ 一条总原则（最重要）
模型执行的是「正面语义」，不是「负面约束」——你描述了什么场景，
它就按训练数据里这个场景最常见的样子画。
所以核心不是"不要什么"，而是"要什么"：用具体、能占满画面的正面描述，把翻车的空间挤掉。
负面词只留真正压得住的，压不住的（乱码字/手部特写/法槌/扑克牌）一律改成正面的"空白/排他"写法。

■ 一、必须绕开的点（写了必翻车 → 改设计，别指望提示词补救）
1. 带字的物件（手稿/黑板/牌匾/证书/信件/报纸/图纸/元素表/铭牌）：
   → 不做画面的主体或大特写；当背景 / 远景 / 虚化都可以。
   → 画面里的文字"不追求准确、不做叠加"；叠字层只做底部旁白字幕，画面内文字一律不后期叠加。
   → 不要写"文字虚化"（模型先写字再模糊，照样可辨）；不要写"符号允许清晰"（那是要求它写对，做不到）。
2. 准确的文字/符号/数字（元素符号、原子量、标题、铭文）→ 不要求准确；只要它不当主体、肉眼不刺眼即可。
3. "桌上排列的卡片" → 必变扑克牌。改：图钉钉的不规则小纸片 / 黑板格子 / 卷轴表格。
4. "大厅+长桌+多人"的正式议事场景 → 自动补法槌。
   改：桌面上明写"只有 X、Y，没有任何其他物品"，把桌面占满。
5. 弱风格词（"绘画感写实油画风"）压不住场景默认风格。
   改：用强风格锚点（如"19世纪学院派油画，伦勃朗光，画布纹理可见，厚涂笔触"），每条提示词都重复一遍。
6. 动态效果（叠化、半透明、一闪而过、动画感）→ 静态模型做不了，改静态画面，动态留后期。
7. 抽象概念（时间流动感、宇宙规律）→ 模型只会给最常见联想（时钟/沙漏/法槌）。改：翻译成具体视觉元素。
8. 小区域里的特定小物件（裂缝里的热气球、气泡里的周期表）→ 常被忽略或换成更常见的东西。要么放大成主体，要么去掉。

■ 二、可以写、不要刻意躲的点（出了问题再修，成本很低）
- 手 / 手指：正常写手势即可，不要刻意回避。
  手确实容易被画错，但它属于「低修复成本」问题（掩掉 / 局部改 / 重出一张都容易），
  不值得为它牺牲画面自然度。质量上：只有「一眼可见的明显畸形」才算硬伤，其余交给人工目视。
- 轻微比例、细节怪：不硬卡。
- 若某个镜头确实不想要手：用「纯背影」「双臂收入深色高领外套袖中」，
  不要写"指向（不见手）""持笔（不见手）"这种自相矛盾的指令（模型会优先执行动作）。
  给物品写"羽毛笔搁在桌上、不在手中"，别写"握着笔但不见手"。

■ 三、人物一致性（跨镜）
- 定妆像确认后，后续人物镜头优先用「图生图（img2img）」以定妆像为参考，别纯文生图。
- 纯文生图时，人物描述要极具体并逐镜原样复用（发式/长度/胡须/特征要写到"左眉上方有一颗痣"这种颗粒度）。
- 不确定就让人物用背影/侧影/远景，减少面部一致性压力。

■ 四、提示词骨架（照着填）
[年代+地点+氛围光] + [人物：固定锚定描述，逐镜复用] + [姿态：背影/侧身/双臂收入袖中；需要手就正常写] + [场景物体：用「只有…，没有任何其他物品」排他句] + [背景：模糊暗色墙面，没有空隙] + [强风格锚点] + [负面词：现代物品, 塑料, 电子设备, 卡通, 3D渲染, 水印]

■ 五、每镜只聚焦 1–2 个核心元素
元素越多，每个越不准。复杂信息（周期表+地图+奖章）拆成多镜，别一镜塞完。

■ 六、交付约定
- 必须导出原图，不要从 App 预览界面截图（截图会把界面按钮烤进画面）
- 文件名带图号（如 01-1.png）
- 打包成一个 zip 回传
- 分辨率 ≥1080×1920

■ 七、流程（省返工）
- 先出「定妆像 + 2~3 张关键镜」确认人物和风格，再批量出其余
- 每出 8~10 张就快审一遍，发现系统性问题立刻改后续批次，别等全部出完
- 高危镜头（文字/卡片/议事场景）先测 1–2 张再放大

■ 八、出货后台质检口径（怎么判）
- 🔴 硬伤（必重出）：一眼可见的结构错误——乱码字、明显畸形手、时代穿帮（现代物件）、人物明显换人
- 🟡 存疑（交人目视，不自动废图）：看不清的一律标"疑似"，不许硬判
- 达标线：张数齐 ｜ 0 张乱码字 ｜ 无现代物件 ｜ 废图率 ≤30% ｜ ≥1080×1920
- 「手」不作为硬伤项，除非一眼明显畸形。

          五、负面词精简原则

          旧负面词（15+ 项，很多压不住）：乱码文字, 伪文字, 水印, 畸形手指, 多余手指, 手部特写, 现代服饰, 塑料, 电子设备, 手机, 电脑, 卡通, 3D渲染, 照片质感, 法槌, 扑克牌, 遗体, 棺材, 血迹, DNA双螺旋

          新负面词（只留真正压得住的，6 项）：现代物品, 塑料, 电子设备, 卡通, 3D渲染, 水印

          原则：压不住的（乱码文字／手部特写／法槌／扑克牌）→ 改为正面约束，别放进负面词浪费权重。

          六、流程优化建议（省返工）

          1. 先出定妆像＋2~3 张关键镜确认风格，再批量（本批一次出 44 张，风格漂移后全部返工）。
          2. 文字类镜头：让带字物件不当画面主体（22 张有文字表面全部翻车——根因是「文字当主角」，不是「出现文字」）。
          3. 扑克牌问题 → 分镜阶段换载体（避开「卡片」触发词）。
          4. 法槌问题 → 桌面占满法。
          5. 人物一致性 → 定妆像确认后走图生图。
          6. 审核前移到单镜：每 8~10 张快审一次，别等全部出完才发现系统性问题。

          七、迭代机制与版本历史（活文档）

          约定（2026-10-07 用户定）：用户每出一期图（如某条视频的 40+ 张），会让豆包做一份生图复盘；复盘发来后由我方整合，持续迭代本规则。本页链接固定不变，内容持续更新。

          用户要做的：出图 → 让豆包复盘 → 把复盘原文发来（文件或文字都行）。 每次收到复盘，我方做四件事： 1. 去重合并：多份/含重叠的先合并。 2. 对照现行规则分三类： - 🆕 新增边界/坑（必带「哪一期、几张」） - ♻️ 印证已有条目（累加频次／样本） - ❌ 证伪旧结论 → 保留删除线 + 更正说明，一律不删旧结论（保留追溯） 3. 更新本页：正文 ＋ frontmatter updated ＋ 下方版本历史表；并按「修复成本」重新校准「边界类 / 可修复类」的分栏与松紧。 4. 登记发布：同步 index.md、追加 log.md，发布后把链接发给用户。
